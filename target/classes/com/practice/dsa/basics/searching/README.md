# Searching Basics

Study order:
1. `LinearSearchBasics`
2. `BinarySearchVariants`

Use this folder to learn the contrast between scanning every value and using ordered search space.

## Practice Exercises

- Implement first occurrence, last occurrence, lower bound, and upper bound variants.
- Solve search-insert-position and closest-element style questions.
- Search in a rotated sorted array and find the minimum element in the rotation.
- Find a peak element using binary search on shape instead of exact equality.
- Practice binary search on answer for capacity, speed, or time-limit problems.
