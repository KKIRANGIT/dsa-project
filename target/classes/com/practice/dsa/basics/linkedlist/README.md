# Linked List Basics

Study order:
1. `SinglyLinkedList`
2. `DoublyLinkedListBasics`
3. `ReverseLinkedListBasics`
4. `MiddleNodeBasics`
5. `LinkedListCycleDetectionBasics`

Use this folder to learn pointer movement, node rewiring, and fast-slow pointer basics.

## Practice Exercises

- Reverse a sublist between positions `left` and `right`.
- Remove the `n`th node from the end with a two-pointer gap.
- Merge two sorted linked lists using pointer rewiring only.
- Check whether a linked list is a palindrome using middle-node and reverse-half logic.
- Reorder a list by splitting, reversing the second half, and weaving nodes together.
