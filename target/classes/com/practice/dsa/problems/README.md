# Problems Guide

This folder is the third learning layer.

## Naming Convention

- `LC<number>NameSolver` contains the main solution logic
- `LC<number>NameMain` contains sample inputs and execution flow
- `TopicProblemsMain` runs a small group of problems from the same topic

## How To Study A Problem

1. Open the solver class.
2. Read the class-level explanation first.
3. Understand each state variable.
4. Run the matching `Main` file.
5. Trace the code with a debugger.
6. Re-explain the solution in plain English.
