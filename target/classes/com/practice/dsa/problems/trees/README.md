# Trees

## What To Learn Here

- recursive traversal
- level-order traversal with queue
- subtree rules and value ranges

## Suggested Problem Order

1. `LC104 Maximum Depth of Binary Tree`
2. `LC226 Invert Binary Tree`
3. `LC102 Binary Tree Level Order Traversal`
4. `LC98 Validate Binary Search Tree`

## Common Beginner Mistakes

- confusing preorder/inorder/postorder
- forgetting base cases in recursion
- validating BST using only parent comparison instead of full range
