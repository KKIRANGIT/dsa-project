# Start Here

If you are a beginner, do not start by opening random problem files.

Use this order:

1. Read [01_PROJECT_MAP.md](./01_PROJECT_MAP.md)
2. Read [02_STUDY_SEQUENCE.md](./02_STUDY_SEQUENCE.md)
3. Run beginner-friendly files from `basics`
4. Move to `patterns`
5. Then solve `problems` topic by topic

## What Each Folder Means

- `common`: shared node classes like linked-list nodes and tree nodes
- `basics`: data structures and algorithm building blocks
- `patterns`: reusable interview problem templates
- `problems`: real LeetCode-style implementations

## Beginner Rule

Before reading a problem solution, first understand:

1. the data structure
2. the pattern
3. then the problem

That is the whole idea of this project.
