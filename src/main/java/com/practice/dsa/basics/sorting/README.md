# Sorting Basics

Study order:
1. `BubbleSort`
2. `SelectionSort`
3. `InsertionSort`
4. `MergeSort`
5. `QuickSort`
6. `CountingSortBasics`

Use this folder to compare simple quadratic sorts with faster divide-and-conquer and counting-based sorting.

## Practice Exercises

- Dry-run each sorting algorithm and count comparisons and swaps on the same input.
- Use insertion sort on nearly sorted data and compare it with merge sort and quick sort.
- Build quickselect from your quicksort partition logic.
- Count inversions using merge-sort-style merging.
- Solve problems where sorting is only the first step before scanning or grouping.
