# Trees Basics

Study order:
1. `TreeTraversals`
2. `TreeMetricsBasics`
3. `BalancedTreeBasics`
4. `DiameterOfTreeBasics`
5. `LowestCommonAncestorBasics`
6. `ValidateBinarySearchTreeBasics`
7. `TreeSerializationBasics`
8. `BinarySearchTree`

Use this folder to learn recursive traversal, subtree-based answers, balance/diameter logic, ancestor search, BST validation, serialization, and BST insertion/search/delete.

## Practice Exercises

- Implement preorder, inorder, postorder, and level-order traversal for the same tree.
- Solve height, depth, balance, and diameter in one subtree-return pattern family.
- Use recursion to answer path-sum and root-to-leaf decision problems.
- Solve BST questions such as insert, search, validate, and kth-smallest.
- Rebuild or serialize trees so you understand how traversal order encodes structure.
