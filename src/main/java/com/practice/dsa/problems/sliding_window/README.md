# Sliding Window

## What To Learn Here

- fixed-size windows
- variable-size windows
- frequency tracking inside a window
- maintaining a valid invariant while moving left/right

## Suggested Problem Order

1. `LC121 Best Time to Buy and Sell Stock`
2. `LC3 Longest Substring Without Repeating Characters`
3. `LC424 Longest Repeating Character Replacement`
4. `LC567 Permutation in String`
5. `LC239 Sliding Window Maximum`
6. `LC76 Minimum Window Substring`

## Common Beginner Mistakes

- not knowing when to shrink the left side
- mixing fixed and variable window logic
- forgetting that some windows track counts, not sums
