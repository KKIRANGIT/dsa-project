## Naming Rules

- `LC<number>...` classes map to specific problems.
- `...Solver` contains the main solution logic when a separate solver exists.
- `...Main` provides a runnable entry point or walkthrough.
- `TopicProblemsMain` runs a grouped sample for one topic.
