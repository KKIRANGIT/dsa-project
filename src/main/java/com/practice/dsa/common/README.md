# Common Helpers

Package: `com.practice.dsa.common`

This folder contains the shared node models, support structures, builders, and debug printers reused across the project.

## Current Classes

- `DoublyListNode`
- `Edge`
- `GraphNode`
- `GraphPrinter`
- `Interval`
- `LinkedListPrinter`
- `ListNode`
- `Pair`
- `StructureBuilder`
- `StructureBuilderMain`
- `TreeNode`
- `TreePrinter`

## How To Use This Folder

1. Read these files before topics that rely on custom linked-list, tree, graph, or interval models.
2. Reuse them when debugging problems instead of rebuilding helper structures in every file.
3. Treat the builder and printer classes as support utilities, not the main study target.
