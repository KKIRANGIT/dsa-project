# Study Sequence

This is the recommended learning order for a beginner.

## Phase 1: Core Mechanics

Run these first:

1. `basics/arrays/PrefixSumMain`
2. `basics/arrays/DifferenceArrayMain`
3. `basics/linkedlist/SinglyLinkedListMain`
4. `basics/stack/ArrayStackMain`
5. `basics/queue/CircularQueueMain`
6. `basics/trees/BinarySearchTreeMain`
7. `basics/graph/GraphTraversalMain`

Goal:
- understand what each structure stores
- understand how values move
- understand insertion, removal, and traversal

## Phase 2: Problem-Solving Patterns

Run these next:

1. `patterns/arrays_hashing/PT1FrequencyMapTemplateMain`
2. `patterns/two_pointers/PT1OppositeTwoPointersTemplateMain`
3. `patterns/sliding_window/PT2VariableWindowTemplateMain`
4. `patterns/stack/PT2MonotonicStackTemplateMain`
5. `patterns/binary_search/PT1BinarySearchTemplateMain`
6. `patterns/trees/PT2LevelOrderTemplateMain`
7. `patterns/graphs/PT3MatrixBfsTemplateMain`
8. `patterns/dp/PT2OneDimensionalDpTemplateMain`

Goal:
- learn how interview questions are grouped by pattern
- stop memorizing individual problems blindly

## Phase 3: Easy Problems

Open these first:

1. `problems/arrays_hashing/two_sum/LC1TwoSumMain`
2. `problems/arrays_hashing/contains_duplicate/LC217ContainsDuplicateMain`
3. `problems/two_pointers/valid_palindrome/LC125ValidPalindromeMain`
4. `problems/sliding_window/best_time_to_buy_and_sell_stock/LC121BestTimeToBuyAndSellStockMain`
5. `problems/stack/valid_parentheses/LC20ValidParenthesesMain`
6. `problems/binary_search/binary_search/LC704BinarySearchMain`
7. `problems/linked_list/reverse_linked_list/LC206ReverseLinkedListMain`
8. `problems/trees/maximum_depth_of_binary_tree/LC104MaximumDepthOfBinaryTreeMain`

## Phase 4: Medium Problems

Move here after you understand the easier problems:

1. `LC49 Group Anagrams`
2. `LC347 Top K Frequent Elements`
3. `LC15 3Sum`
4. `LC424 Longest Repeating Character Replacement`
5. `LC239 Sliding Window Maximum`
6. `LC739 Daily Temperatures`
7. `LC875 Koko Eating Bananas`
8. `LC102 Binary Tree Level Order Traversal`
9. `LC200 Number of Islands`
10. `LC322 Coin Change`

## Phase 5: Harder Problems

Move here only after the medium set feels comfortable:

1. `LC76 Minimum Window Substring`
2. `LC42 Trapping Rain Water`
3. `LC72 Edit Distance`
4. `LC743 Network Delay Time`

## Practical Rule

When a problem feels hard:

1. go back to the matching `basics` topic
2. read the matching `patterns` topic
3. return to the problem
