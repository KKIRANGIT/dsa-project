# Java DSA Project

This repository is a Java 17 Maven workspace for studying data structures, algorithm patterns, LeetCode-style problems, and object design in one place.

## Live Coverage

- `common`: 12 shared helper classes
- `basics`: 19 topics, 74 implementation classes, 74 runnable Main classes
- `patterns`: 19 topics, 88 templates, 88 runnable demos
- `problems`: 18 topics, 123 problem folders, 246 problem Java files, 18 topic runners, 8 tests
- `designpatterns`: 5 categories, 42 runnable demos

## Stack

- Java 17
- Maven
- JUnit 5

## Package Root

`com.practice.dsa`

## Repository Layout

~~~text
src/main/java/com/practice/dsa/
  common/
  basics/
  patterns/
  problems/
  designpatterns/
~~~

## Quick Start

1. Read `00_START_HERE.md`.
2. Skim `01_PROJECT_MAP.md` for the five learning layers.
3. Use `02_STUDY_SEQUENCE.md` if you want a guided order.
4. Run a `*Main` class in `basics` before jumping into other layers.
5. Use the topic READMEs to navigate the exact class inventory.

## Typical Commands

~~~bash
mvn test
mvn package
~~~
